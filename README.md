## The Funniest Office Joke, Judged Head to Head

One deadpan line, 120 characters: a 15-minute meeting called to cut meetings runs 47 minutes, and the "could've been an email" verdict arrives as a reply-all from inside the meeting itself. Setup, double turn, punchline last.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
